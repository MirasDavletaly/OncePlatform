# OncePlatform

Веб-портал с сервером на Go и интерфейсом React/TypeScript.

## Запуск

1. Скопируйте `.env.example` в `.env` и задайте собственные параметры и секреты.
2. Соберите и запустите контейнеры:

```sh
docker compose up -d --build
```

Доступные команды перечислены в `Makefile` (`make help`). Настройка для Synology находится в `deploy/synology/`.

## Разработка

```sh
make build
make test
```

Опубликованы исходники без локальных данных, ключей, архивов сборок и истории прежнего репозитория. Для запуска нужны зависимости, указанные в `go.mod` и `web/package.json`.
